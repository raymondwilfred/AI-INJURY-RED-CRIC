# 🏏 Cricket Injury Reduction Using AI

An end-to-end AI and computer vision project designed to identify high-risk body postures and biomechanical movement patterns in cricket players, particularly fast bowlers and fielders.

The system analyzes cricket videos using **pose estimation, joint-angle analysis, and machine learning** to identify potentially risky movements during phases such as **Back Foot Contact (BFC), Front Foot Contact (FFC), and Ball Release**.

### ⚙️ Main Technologies

* YOLOv8-Pose  – Human pose and keypoint extraction
* **Computer Vision** – Cricket video and movement analysis
* **Biomechanical Analysis** – Joint angles and movement patterns
* **Machine Learning** – Injury-risk classification
* **Streamlit** – Interactive analysis dashboard

### 🎯 Key Analysis

* Front knee flexion during landing
* Elbow extension during bowling
* Shoulder–hip counter-rotation
* High-stress body regions
* Bowling action phases
* Potential injury-risk movement patterns
